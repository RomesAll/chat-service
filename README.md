# Описание

Сервис онлайн-чата для общения между пользователями в режиме реального времени. Взаимодествие между клиентами происходит с помощью WebSockets.
Данный сервис использует E2EE шифрование для передачи сообщений между пользователями.

*E2EE (End-to-End Encryption), или сквозное шифрование — это способ передачи данных, при котором доступ к сообщениям имеют только отправитель и получатель. 
Любые третьи лица, включая интернет-провайдеров, хакеров и даже серверы самой программы обмена сообщениями, не могут расшифровать эти данные.*

feature сервиса:
1) чаты: приватные и групповые (комнаты)
2) передача файлов
3) сохранение истории сообщений в БД
4) кеширование данных
5) управление комнатами (CRUD операции + выпуск временного токена, со счетчиком, для вступления в комнату)
6) управление пользователями (CRUD операции)
7) JWT auth + подтверждения входа, регистрации через одноразовый код, который отправляется по email
8) управление ключами пользвателей (сохранение зашифрованных приватных и публичных ключей, для расшифровки старых сообщений)
9) celery задачи для отправки кода подтверждения
10) аудит действий пользвателей через mongodb
11) админ панель (с помощью которой можно тестировать)

feature, которые будут реализованы дальше:
1) полноценный frontend
2) отправка голосовых сообщений
3) асинхронный стиль
4) более детальное управление комнатами
